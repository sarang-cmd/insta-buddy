2. Using the software

You run Insta Buddy on your own device. You choose which image files to add, which edits to apply and which files to export. You are responsible for having the right to use those files and for checking any local rules that apply to them.

The repository does not provide a hosted service, a user account or a support commitment. A separate support policy should be added here if one is offered: [Support policy].

3. Your photos and content

You keep ownership of your photos and any captions or edits you create. In the current version, photos, analysis results and edits are held in memory for the active session. Refreshing the page or starting a new trip clears that session. Export writes a ZIP file to your device when you choose to export.

The app does not include a photo database in version 1. If a future version adds persistent storage, this section must be updated before that version is released.

4. Optional AI providers

AI providers are optional and off by default. If you configure a provider and turn on an AI feature, the app may send text, photo metadata and, with a separate image upload opt-in, image data to that provider. Local providers may receive requests on your own machine. You are responsible for your provider accounts, API keys and the provider's own terms.

AI output can be wrong. Keeper choices, second opinions, captions and erase results should be reviewed before you publish them.

5. No warranty

The software is provided as is. The analysis uses heuristics. People detection, wire detection, extend, captions and keeper ranking can all produce imperfect results. The maintainers do not promise that the software will be uninterrupted, error free or suitable for every photo set.
